## Apa itu SELECT?

`SELECT` adalah perintah SQL untuk mengambil data dari tabel. Hasilnya berupa kumpulan baris yang bisa dibaca oleh aplikasi atau pengguna.

Bayangkan kita punya tabel `customers`:

| id  | nama | kota     | email            |
| --- | ---- | -------- | ---------------- |
| 1   | Sari | Bandung  | sari@example.com |
| 2   | Budi | Jakarta  | budi@example.com |
| 3   | Rani | Surabaya | rani@example.com |

## Mengambil semua kolom

```sql
SELECT *
FROM customers;
```

Tanda `*` berarti semua kolom. Cara ini praktis untuk eksplorasi, tetapi untuk aplikasi produksi sebaiknya sebutkan kolom yang benar-benar dibutuhkan.

## Mengambil kolom tertentu

```sql
SELECT nama, kota
FROM customers;
```

Hasilnya hanya berisi kolom `nama` dan `kota`, sesuai urutan yang ditulis.

## Memberi alias

Alias membuat nama kolom pada hasil lebih mudah dibaca:

```sql
SELECT
    nama AS nama_pelanggan,
    kota AS kota_asal
FROM customers;
```

Kata kunci `AS` bersifat opsional, tetapi menuliskannya membuat query lebih jelas.

## Mengurutkan hasil

Tambahkan `ORDER BY` untuk mengurutkan data:

```sql
SELECT nama, kota
FROM customers
ORDER BY nama ASC;
```

`ASC` berarti menaik (A ke Z), sedangkan `DESC` berarti menurun.

<Callout type="info" title="SELECT tidak mengubah data">
  `SELECT` hanya membaca data. Untuk menambah, mengubah, atau menghapus data, kamu memerlukan
  `INSERT`, `UPDATE`, atau `DELETE`.
</Callout>
